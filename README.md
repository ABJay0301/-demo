# 课表提醒 · PWA 课程提醒工具

纯前端（HTML + CSS + 原生 JS，零依赖）实现的手机课表提醒应用：周课表可视化、单双周课表、
学期周次识别、自定义提前提醒、到点弹出手机通知，可添加到桌面图标全屏打开，数据只存在本机。

## 两个版本，按需选一个

| 版本 | 文件 | 适合场景 |
| --- | --- | --- |
| **多文件版**（推荐） | `index.html` + `styles.css` + `app.js` + `manifest.json` + `sw.js` + `icons/` | 部署到静态托管，完整能力：静态 manifest、离线缓存、安卓通知 |
| **单文件版** | `课表提醒-单文件版.html`（约 136 KB，全部内联） | 只想拿一个文件，随手丢到任意 https 托管 |

单文件版把 CSS、JS、图标（base64）、manifest、Service Worker 源码全部内联在一个 HTML 里：

- manifest 由页面在运行时生成并注入，图标是内联的 data URI；
- Service Worker 不能内联执行（浏览器要求独立的脚本文件），所以单文件版默认只缺这一个文件：
  到「设置 → 通知提醒 → 通知支持文件 sw.js」点「下载」，把它放到与页面同一个目录，刷新即可开启安卓通知。
  这一步只影响**通知**，课表、数据保存、加桌面图标都不受影响。

## 文件结构（多文件版）

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：下一节课卡片、周课表、课程列表、设置、添加/编辑课程弹层 |
| `styles.css` | 全部样式：柔和渐变背景、卡片布局、课表网格、弹层动画、刘海屏安全区适配 |
| `app.js` | 全部逻辑：数据存取、课表渲染、周次推算、表单校验、提醒调度、通知、导入导出 |
| `manifest.json` | PWA 清单：应用名、图标、全屏模式、主题色、桌面图标长按快捷方式 |
| `sw.js` | Service Worker：离线缓存 + 弹出通知 + 点击通知回到应用 |
| `icons/` | 应用图标（192/512/180 以及 maskable 版本、SVG 版） |

## 怎么跑起来

Service Worker 和通知要求**安全上下文**，所以请用 http(s) 打开，不要直接双击 `index.html`：

```bash
# 本地预览（在 outputs 目录里执行）
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

想放到手机上用，把 `outputs/` 整个目录传到任意静态托管即可（GitHub Pages、Vercel、Netlify、
对象存储，或局域网里电脑起的服务）。必须是 **https**（localhost 例外）。

## 添加到手机桌面

- **安卓（Chrome / Edge）**：右上角菜单 →「安装应用 / 添加到主屏幕」。
- **苹果（Safari）**：底部「分享」→「添加到主屏幕」。
- 之后从主屏图标打开即为全屏，没有地址栏。

## 单双周与学期周次

- 每门课可以设成 **每周 / 单周 / 双周**（添加课程弹层里的「上课周次」）。
- 「设置 → 学期与周次」里填 **开学第一周的周一** 和 **学期周数**（默认 20 周），
  应用据此推算当前是第几周、属于单周还是双周：
  - 周课表右上角显示「第8周·双」这样的标签，标题下方是该周的日期区间；
  - 切到某一周时，单双周课程按该周的奇偶自动显示 / 隐藏；
  - 「下一节课」卡片和上课提醒都会跳过不上课的周次；
  - 课程列表会标注「单周 / 双周」以及「本周不上」。
- 学期外的周次（开学前、假期）不按单双周过滤，直接显示全部课程，方便查看整张课表。
- 修改开学日期会自动对齐到那一周的周一，保证口径一致；点「设为本周」可把本周当作第 1 周。

## 关于提醒（重要）

- 首次使用请到「设置 → 系统通知权限 → 开启」，并在系统里允许本应用发通知。
- 苹果手机需要 **iOS 16.4 及以上**，并且**必须从主屏图标打开**才能收到网页通知。
- 纯前端应用没有后台服务，浏览器可能冻结后台页面的定时器。本应用的做法是：
  页面打开时每 15 秒巡检一次，**回到前台时自动补发还没错过的提醒**（已经开课的不会补发）。
- 想让提醒尽量准时，建议：把应用加到桌面，并在系统设置里允许它「自启动 / 后台活动 /
  无限制省电」（安卓各家名称略有不同）。

## 数据

- 课程与设置保存在浏览器 `localStorage`，不上传、不联网。
- 清理浏览器数据、换浏览器、换手机都会清空；长期使用请用「设置 → 导出备份」保存 JSON
  （备份里包含学期设置，换设备后单双周不会错位）。
- 存储结构做了向前兼容：老数据没有「上课周次」字段时，默认按「每周」处理。

## 想自己改点什么

源码在 `outputs/` 下的 `index.html` / `styles.css` / `app.js`，改完执行 `node ../work/build-single.js`
即可重新生成单文件版（打包脚本会逐字节校验内联结果与源文件一致）。

- **课表时间范围**：默认至少显示 07:00–22:00，有更早 / 更晚的课会自动扩展；
  查看本周时还会自动把「此刻」包进可视范围（见 `app.js` 的 `calcGridRange`）。
- **每小时高度 / 时间列宽**：改 `styles.css` 里 `.table` 的 `--hour-h`、`--time-col`
  （JS 会读取该变量来定位课程块）。
- **配色**：改 `styles.css` 顶部的 CSS 变量，以及 `app.js` 里的 `PALETTE` 数组（8 种柔和色）。
- **默认提前提醒、巡检间隔、学期默认值**：改 `app.js` 顶部的 `DEFAULT_SETTINGS`、`SWEEP_MS`。
